MLOps for Text Emotion Classification

Student project exploring the operational machine learning lifecycle with MLflow through a text mood classification application.

Python · MLflow · Machine Learning · API

Project Overview

This student MLOps project used a text mood classification task as a context to explore MLOps. The main goal was to explore how a machine learning model can move from experimentation to integration into a running application.

The prediction task itself was intentionally simple. The model was trained to classify the main emotion in a text. The main objective was to learn how to structure, track, compare and serve machine learning experiments using MLflow.

MLflow Workflow

The project was built around MLflow and covered several stages of the model lifecycle:

  • training and testing different classification algorithms,
  • tracking experiments, parameters and evaluation scores,
  • comparing model runs through the MLflow interface,
  • managing trained models and selecting suitable versions,
  • exposing predictions through an API,
  • connecting the selected model to an application.

Key Takeaways

This project introduced me to the practical use of ML in industry. It showed me how those projects can be structured beyond notebooks. It helped me understand how to keep track of model runs, compare different approaches, organize model deployment and connect a trained model to an application through an API. Moreover, I enjoyed working on this project, which made me want to pursue similar projects in the future.
